# Политика конфиденциальности (Privacy Policy)

**Последнее обновление:2026-10-31**

Эта Политика конфиденциальности описывает, как личное приложение **n8n YouTube Auditor** (далее — «Приложение») собирает, использует и защищает вашу информацию.

Приложение является личным инструментом разработчика и не предназначено для коммерческого использования или сбора данных третьих лиц.

### 1. Какую информацию мы собираем
Приложение использует официальные API Google (YouTube Data API v3 и YouTube Analytics API) для получения статистики исключительно **вашего собственного** YouTube-канала. 
Собираемые данные могут включать:
*   Названия и описания видео.
*   Публичную статистику (просмотры, лайки, комментарии).
*   Приватную аналитику канала (время просмотра, удержание аудитории, источники трафика).

### 2. Как мы используем информацию
Полученные данные используются исключительно для внутренних целей:
*   Формирование отчетов и аудита контента.
*   Передача обезличенных метрик в API Google Gemini для генерации рекомендаций и контент-плана.
*   Отправка готовых отчетов в ваш личный Telegram-бот.

### 3. Передача данных третьим лицам
Мы не продаем, не обмениваем и не передаем ваши данные третьим лицам. Данные передаются только в следующие сервисы для обеспечения работы Приложения:
*   **Google API** (для получения статистики и анализа через Gemini).
*   **Telegram** (для доставки отчетов).
*   **Apify** (если используется для сбора данных из других соцсетей).

### 4. Соответствие политике Google API
Использование Приложением информации, полученной из API Google, соответствует [Политике конфиденциальности данных пользователей API Google](https://developers.google.com/terms/api-services-user-data-policy), включая требования к ограниченному использованию (Limited Use).

### 5. Безопасность и хранение данных
Доступ к API осуществляется через защищенные OAuth 2.0 токены. Сами данные не хранятся на постоянной основе дольше, чем это необходимо для формирования отчета, и обрабатываются на защищенном частном сервере (VPS).
